# India-Macroeconomic-Analysis
Exploratory data analysis of India's post-1991 macroeconomic indicators (GDP growth, GDP in USD, CPI, unemployment, capital formation, trade, and current account) using Python, Pandas, and Matplotlib to uncover growth and trade trends.
# India Macroeconomic Indicators Analysis (1991–2019)

### Overview
Exploratory data analysis of India's post-1991 economic performance using **Python (Pandas, Matplotlib)**.

### Key Insights
- **GDP Expansion:** India's economy expanded nearly 10x from $0.27T (1991) to $2.84T (2019).
- **Investment-Driven Growth:** Gross capital formation above 38% (2006–2012) strongly correlated with sustained 7–8%+ GDP growth.
- **Trade Deficit Dynamics:** Imports outpaced exports as a percentage of GDP, driving persistent current account deficits.
